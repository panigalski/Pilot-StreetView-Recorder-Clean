# ORIGINAL CAMERA-STYLE MAIN LAYOUT V2.0

The main preview screen now follows the visual hierarchy of the native Labpano Camera screen:

- full-screen live preview with no separate visible title bar;
- GPS/navigation indicator at the upper left;
- live picture-adjustment summary in the upper centre;
- native-style Pro badge at the upper right;
- circular picture-adjustment button at the lower left;
- large central record/stop control;
- circular save-location button at the lower right;
- temporary status and recording time overlays over the preview.

The lower-left button opens Picture Adjustments. The lower-right button opens Recording Destination.
No GitHub Actions workflow files are changed.
